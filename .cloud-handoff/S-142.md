## 引き継ぎ

- S-144 で特に注意する点（S-142 で測定済み）: Python の `expovariate` は `-log(1-u) / (1.0/mean)` で、Rust 現行の `-mean * ln(1-u)` とは最後の ulp が約 1/3 の draw で違う。bit 等価には除算の形を揃える。`generate_intervals` の `math.fsum` vs 逐次和、`generate_ratios` の偶数丸め vs `f64::round` も一般には違う（fixture の (v, n) では一致することを測定）。
- 未確認: Rust `f64::ln` と CPython `math.log` の bit 一致（同一ホストの glibc なら一致するはずだが S-143 の固定列テストで確かめる）。`SmallRng` 固有の値を pin している Rust unit test の有無。
- `getstate/setstate` は fixture 再生に不要（`reset()` 専用。Rust は clone で等価）。
