## 決めたこと（S-239 §5 の推しどおり）

- `Percentile.direction` の既定は `above`。`target` は `irt` のみ（`IRT` はエラー）。`AdjustingSchedule.target` は `ratio`/`interval` のみ。
- DRO のキーは `dro_type`。
- 整数パラメータは JSON 整数のみ（`5.0`、負数は `Config` エラー）。`rank` は u8、`response_count`/`frco`/`n_comparisons`/PR の `start`・`step_size` は u32 に範囲検査。
- 省略可の値・入れ子は「キー無し」と `null` を同じに扱う（`params` 自体の欠落/`null` も空として扱う）。
- `LimitedHold` の内側（FI/VI/RI）の型分岐は `from_spec` の中に閉じた。それ以外の内側は `Config` エラー。
- conformance.rs の旧実装は panic していたが、`from_spec` はすべて `ContingencyError::Config` を返す。入れ子のエラーは `Alternative.second: ...` のように経路を付ける。
